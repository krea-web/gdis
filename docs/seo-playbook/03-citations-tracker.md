## 🎯 Cosa fare dopo le 22 citation

Una volta che almeno 10-15 sono ✅ verificate:

1. **Update `Organization.sameAs` schema**: il file [src/lib/siteSchema.ts](src/lib/siteSchema.ts) ha già `BUSINESS_INSTAGRAM` e `BUSINESS_GBP` in `sameAs`. Aggiungiamo le URL canoniche delle citation Tier 1 (Tripadvisor, PagineGialle, Virgilio, Infobel) come array. Questo invia un **Google Knowledge Graph signal** che consolida la tua identità entity.

2. **Run citation audit**: dopo 30 giorni, useremo Moz/Whitespark per verificare quanti citation Google ha **effettivamente trovato** vs quante hai sottomesso. Pattern atteso: 70-80% indicizzate dopo 30g.

3. **Backlink follow-up**: alcune di queste piattaforme (Tripadvisor, ProvenExpert, Infobel) permettono link diretto al sito (dofollow o nofollow misti). Ogni dofollow link = backlink reale.

4. **NAP audit cross-platform**: ogni 3 mesi run un grep automatizzato (posso fare io) che verifica che la NAP sia identica ovunque. Se uno cambia tipo di carattere o spaziatura, Google smette di consolidare = perdita signal.
